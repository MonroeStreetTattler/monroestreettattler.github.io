Update the Dog Map

A tool for the editor of the Tattler. Readers never see this page.

What this is for. Your dog map needs to know where each spot sits on the globe. Neighbors submit addresses, not map coordinates, so somebody has to look each one up. This page does that looking up, once, and gives you a file to save. The map then reads that file and draws every pin instantly.

When to run it. Whenever a few new submissions have come in. Once a month is plenty. Nothing breaks if you forget. The map falls back to looking up new spots itself, just more slowly.

What happens when you press the button. It reads your form responses, checks each address, and shows you a running list: a green tick for spots it found, a red cross for ones it couldn't. Give it about a second per spot. When it finishes, you'll get a block of text and instructions for where to paste it.

Step 1. Copy this

This is the finished list of spots and their coordinates. You don't need to understand it or edit it, just move it across intact.

Step 2. Put it on the site

  1. Go to dog-map-data.json on GitHub.
  2. Click into the text, select all of it, and delete it.
  3. Paste what you copied above.
  4. Scroll down and click the green Commit changes button.

The map updates the next time anyone loads it. If any spots came back with a red cross above, fix their addresses in the responses sheet and run this again.
